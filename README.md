# embedding-library

`embedding-library` is a C library for quantizing, storing, and performing similarity calculations on vector embeddings. It is specifically designed to manage 512-dimensional `int8` vectors, utilizing hardware-accelerated SIMD instructions to perform operations like dot products and cosine similarities.

## Architecture & Features (Why use it)

Vector embeddings generated by machine learning models (like LLMs) are typically arrays of 32-bit floats. In large retrieval systems, storing and comparing millions of these floats becomes bottlenecked by memory bandwidth. This library mitigates that by compressing vectors into 8-bit integers and structuring memory for fast retrieval.

* **Hardware-Accelerated Math:** The library conditionally compiles vector math using AVX-512, AVX2, or ARM NEON intrinsics depending on the host architecture. It falls back to standard scalar loops if no SIMD extensions are available.
* **Quantization:** Provides routines to scale and clamp 32-bit `float` arrays down to `int16_t` and `int8_t`.
* **Chunked Memory Allocation:** The `int8_embedding_table` avoids large, monolithic reallocations. Embeddings are stored in discrete "nodes," each containing exactly 512 embeddings. This ensures stable memory usage as the dataset grows.
* **Precomputed Norms:** Cosine similarity requires the magnitude (L2 norm) of both vectors. When an embedding is added to the table, its norm is calculated once and cached as a `double`. Subsequent cosine similarity checks require only a fast integer dot product and a scalar multiplication.
* **Binary Serialization:** The table supports append-only binary serialization to disk. It detects and truncates partial or corrupt records automatically upon loading.

*(Note: The `int8_embedding_table` structure currently hardcodes the embedding dimension to 512 elements).*

## Usage (How to use it)

The primary structures and functions are exposed via `int8_embedding_table.h` and the quantization headers.

### 1. Quantization and Math

You can use the library strictly for its SIMD math operations and quantization logic.

```c
#include "embedding-library/int8.h"

float float_vec[512] = { /* ... 512 float values ... */ };
int8_t int8_vec[512];

// Quantizes the floats into the -128 to 127 range based on the maximum absolute value
int8_from_floats(float_vec, 512, int8_vec);

// Calculate the dot product using hardware intrinsics (AVX/NEON)
int32_t dp = int8_dot_product(int8_vec, int8_vec, 512);

```

### 2. Table Management and Similarity

The table structure manages the lifecycle of the embeddings, caching their norms for rapid comparison.

```c
#include "embedding-library/int8_embedding_table.h"
#include <stdio.h>

int main() {
    // Initialize a table. Passing 0 uses the default initial capacity.
    int8_embedding_table_t *table = int8_embedding_table_init(0);

    int8_t vecA[512] = { /* ... */ };
    int8_t vecB[512] = { /* ... */ };

    // Add embeddings to the table. 
    // Passing -1.0 for the norm tells the library to calculate it automatically.
    ssize_t idxA = int8_embedding_table_add_embedding(table, vecA, -1.0);
    ssize_t idxB = int8_embedding_table_add_embedding(table, vecB, -1.0);

    if (idxA >= 0 && idxB >= 0) {
        // Calculate cosine similarity using the cached norms and SIMD dot product
        double similarity = int8_embedding_table_cosine_similarity(table, idxA, idxB);
        printf("Similarity: %f\n", similarity);
    }

    // Save the table to disk
    int8_embedding_table_serialize(table, "embeddings.dat");

    int8_embedding_table_destroy(table);
    return 0;
}

```

### 3. Loading from Disk

You can reconstruct a table directly from the binary file. The deserializer maps the raw bytes back into the chunked node structure.

```c
#include "embedding-library/int8_embedding_table.h"

// Reconstructs the table. Returns NULL if the file is missing or totally invalid.
int8_embedding_table_t *table = int8_embedding_table_deserialize("embeddings.dat");

if (table) {
    size_t total = int8_embedding_table_size(table);
    printf("Loaded %zu embeddings.\n", total);
    int8_embedding_table_destroy(table);
}

```

## Internal Module Layout

* **`float.h` / `int16.h` / `int8.h**`: Routing headers that expose the math and quantization functions. They `#include` the specific hardware implementations based on compiler flags.
* **`x86/` & `arm/**`: Contains the architecture-specific SIMD intrinsics (AVX-512, AVX2, NEON) for dot products.
* **`fallback/`**: Standard C implementations of the math routines used when hardware extensions are unavailable.
* **`int8_embedding_table.c`**: Implements the memory management, storage nodes, and binary serialization for the 512-dimensional embedding collections.
